# CONNECTED COMPONENTS

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **A SCANNER DARKLY**.

CONNECTED COMPONENTS — A SCANNER DARKLY: after thresholding, an image is just lit and unlit pixels — but which lit pixels are the SAME object? A flood-fill answers it: touch one bright pixel, spread to every bright neighbour, paint the whole island one colour, and count the islands. Objects, counted, from pixels. ⚑ LIVE full-house instrument: a field of blobs, each labelled its own colour, splitting and merging as the brightness cutoff slides; the blobs in 3D; tesseract 4D + shadow + toddler. ◆ LIT: label by repeated 4-connected flood-fill; each fill is exactly one object; a fail-loud self-check runs a fixed 3-blob image and throws unless the labeller returns exactly 3 — a deterministic graph traversal, not an estimate. ▲ AMBER: 4-connectivity here (8 would merge diagonals), a global cutoff mislabels uneven light (watershed handles that). The count is exact. Node-verified. AVAN, with David Lee Wise (ROOT0).
